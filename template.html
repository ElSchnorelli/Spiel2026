Einmalig einrichten Der Button startet auf GitHub die Abfrage der drei Shops. Dafür braucht diese Seite einen Schlüssel, der nur in deinem Browser gespeichert wird.
  1. Neuen Fine-grained Token anlegen, Ablaufdatum nach Wunsch.
  2. Bei „Repository access“ nur dieses Repo auswählen.
  3. Unter „Permissions“ bei Actions „Read and write“ wählen, dann den Token erzeugen.
  4. Den Token hier einfügen und speichern.
Ohne Token: Abfrage direkt auf GitHub starten („Run workflow“ klicken).
